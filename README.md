# Kyvvu — public issue tracker

This repository holds public issues for Kyvvu: the in-process Agent Security Kernel (kyvvu-engine), the SDK, and [platform.kyvvu.com](https://platform.kyvvu.com). It contains no code.

## Reporting behavior

Use the **Report** form. A report needs three things: a minimal example that runs as-is, the actual output you observed, and your exact setup (versions, install method). Reports that cannot be reproduced from what is in the issue are closed.

Before filing, check the documentation at [docs.kyvvu.com](https://docs.kyvvu.com) — the task lifecycle, rules reference, and trace format are all documented there, and behavior that matches the docs is not a bug.

## Questions and requests

Use the **Question / request** form. This includes beta signup problems, feature requests, and anything that doesn't fit the report format.

## Security

If you believe you have found a vulnerability, do not open a public issue. Email security@kyvvu.com.
